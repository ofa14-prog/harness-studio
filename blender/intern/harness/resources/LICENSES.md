# Bundled third-party assets

* **Material Symbols** (filled, rounded) by Google — Apache License 2.0
  (https://github.com/google/material-design-icons). `resources/icons/ui/`.
* **Simple Icons** brand marks — CC0 1.0 (https://simpleicons.org), drawn in each brand's colour from
  Simple Icons' data (dark colours shown white on the dark theme). `resources/icons/brands/`.
* **fal.ai** mark (`brands/fal.png`) — fal's own icon from fal.ai, used only to identify fal as the provider.
  Brand marks remain trademarks of their owners and are used only to identify the provider.
* **Instrument Sans** (The Instrument Sans Project Authors), **Cabin** (The Cabin Project Authors) and
  **Notable** (The Notable Project Authors) — SIL Open Font License 1.1, from the Google Fonts
  repository; static weights cut from the variable fonts. `resources/fonts/` (OFL-*.txt).
* **fal_catalog.json** — model list and input fields converted from the person's Openfield
  add-on (GPL-3.0-or-later).
* Blender's own interface icons (`release/datafiles/icons_svg`) — part of Blender, GPL.
